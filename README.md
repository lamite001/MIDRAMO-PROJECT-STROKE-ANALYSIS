# MIDRAMO-PROJECT-STROKE-ANALYSIS

# PROJECT TOPIC: Stroke Risk Analysis  

## PROJECT OVERVIEW
This data analysis of patient health records aims to identify 
factors associated with stroke occurrence. By analysing the data and 
generating insights that the various parameters in the data received 
we seek to gather enough insight to Understand which patient characteristics
are associated with stroke, using a dataset of 5,110 patient records, and 
data-driven recommendations for further modeling or clinical screening
from the insight gotten and to know the best performance of our data.
